Privacy

Rooted in the Word — Reading Journal
Short version: this app has no server, no account, and no analytics. Everything you enter — reading progress, notes, highlights, your roster, meetings — is stored only in your own browser, on your own device.

What's stored, and where

All of the following is saved using your browser's local storage, on your device only. It is never transmitted anywhere by this app:

  • Your reading plan start date, pace, and checklist progress
  • Notes you write for each day's reading
  • Verses you highlight (only the verse position is stored — never the Bible text itself)
  • Your group roster (names, phone numbers, emails you add)
  • Meetings you schedule and attendance you record
  • Your appearance, font, and Bible-version preferences, and your ESV API key if you add one

Clearing your browser's site data, using a different browser, or switching devices will remove or not include this information, since nothing is backed up anywhere automatically. Use the Export feature in Settings to make your own backup file whenever you'd like one.

Requests that leave your device

Two things this app does reach out to the network for, both triggered only when you tap "read in app":

  • api.esv.org — if you've added your own free ESV API key, passage text is fetched directly from Crossway's ESV API using that key. This app does not have or use its own key; each person supplies their own. Passage text is kept in memory only while the reader is open and is not saved to your device between visits.
  • bible-api.com — used for the free public-domain translations (KJV, WEB, ASV, BBE), the same way and with the same no-storage handling.

Neither of those requests includes your name, notes, roster, or any other personal information — only the Bible reference you asked to read.

Sharing features

The Message, Share, and Invite buttons hand off to your device's own Messages or Mail app (or its native share sheet) with a pre-filled message. Nothing is sent by this app itself — you choose whether to actually send it, and it goes directly from your device to whoever you pick, the same as writing that text yourself.

No ads, no tracking, no cookies

This app doesn't use cookies, analytics, or advertising of any kind, and doesn't share data with any third party other than the two Bible-text services above, only when you request a passage.

If you're using a copy someone else hosts

This app is open-source HTML/JavaScript that anyone can host (for example, on GitHub Pages). Whoever hosts the copy you're using doesn't receive your data either — it's a static file with no server-side component, so there's nothing for a host to collect even if they wanted to. If you have questions about a specific hosted copy, ask whoever shared the link with you.
